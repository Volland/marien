# Project

This directory defines the high-level concepts, business logic and architecture of the project in markdown, managed with the `tg` CLI (compatible with lat.md). Run `tg check` to validate it.

- [[code-ontology]] — shared vocabulary of intent types and typed edges between intent and code
- [[overview]] — what Marien is: a Lean 4 LadybugDB extension running LeanElpi rules over the graph
- [[decisions]] — architecture decisions from the design interview of 2026-10-31
- [[constraints]] — limits of LadybugDB, LeanElpi and the Lean runtime that force those decisions
- [[changes]] — the OpenSpec changes, one per milestone, in build order
- [[architecture]] — system context, layers, call lifecycle, data model and deployment, with diagrams
